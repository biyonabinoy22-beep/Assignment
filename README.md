# Excel Product Data Analysis

## Overview

A basic Excel data analysis project performed on a product dataset using common formulas and text functions.

### Tasks Performed

* Calculated **Sum, Count, Average, Minimum, and Maximum** price.
* Categorized products using the **IF** function into High Price and Standard Price.
* Used **SUMIF** and **COUNTIF** for category and price-based analysis.
* Extracted information from Product IDs using **LEFT, RIGHT, and MID** functions.

### Excel Functions Used

`SUM` · `COUNT` · `AVERAGE` · `MIN` · `MAX` · `IF` · `SUMIF` · `COUNTIF` · `LEFT` · `RIGHT` · `MID`

**Skills:** Excel Data Analysis · Data Categorization · Conditional Functions · Text Functions
